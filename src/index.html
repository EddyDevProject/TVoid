TVoid

Togli la roba inutile dalla tua Android TV. Niente root, niente cavi, tutto reversibile.

Come attivo l'ADB sul TV?
  1. Impostazioni → Preferenze dispositivo → Informazioni
  2. Premi OK 7 volte su Build
  3. Opzioni sviluppatore → attiva Debug USB (e debug di rete, se c'è)
  4. Alla prima connessione accetta «Consenti debug USB?» sul TV
